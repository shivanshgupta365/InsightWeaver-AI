# Contributing

Thank you for improving InsightWeaver. Open an issue for substantial product or schema changes. Keep changes small, evidence-backed, and privacy preserving.

1. Fork the repository and create a focused branch.
2. Run `npm install` and `npm run check`.
3. Add a regression test for pipeline or security behavior.
4. Never commit source datasets, credentials, `.env` files, or production exports.
5. Explain user impact, data-boundary impact, and verification in the pull request.

By participating, you agree to the [Code of Conduct](CODE_OF_CONDUCT.md).
